# SRMS Events

SRMS Events is a college event registration portal for SRMS College of Engineering & Technology, Bareilly. Students can explore and register for campus events, while administrators manage events and registrations.

**Live website:** [srmsevents.vercel.app](https://srmsevents.vercel.app/)

## Tech stack

- Next.js 16
- React 19 and TypeScript
- Tailwind CSS and shadcn/ui
- Supabase

## Run locally

```bash
git clone https://github.com/ruxaen/SRMS-Events.git
cd SRMS-Events
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
